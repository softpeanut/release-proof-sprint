# Release Proof Sprint — Shopstr service terms

Last updated: August 28, 2026.

These terms apply only to the separate Shopstr offer. The existing landing page remains an
interest-only path and does not collect payment.

## Price and exact scope

The fixed price is **100,000 sats** for one public GitHub repository and one critical release path.
The completed handoff contains:

- 3–7 observable checks with explicit pass and fail conditions;
- one repository-native verification command or test contract when safely feasible;
- one sample passing evidence pack and one sample blocking evidence pack;
- one Markdown reviewer handoff; and
- one revision responding to a single consolidated review.

The delivery target is **three business days** after the seller has accepted the scope, verified
payment, and confirmed that every required public input is complete and safely usable.

## Public-only intake and authorization

The order may contain only a GitHub username, a public repository URL, and a short non-sensitive
description of one release path. Do not provide a real name, email address, postal address, phone
number, private repository, private code, source archive, customer data, production data,
credential, secret, token, payment proof, production access, or private link.

The buyer must own the repository or have authority to request the proposed contribution. Delivery
is a draft pull request or public patch for review. The seller does not merge, deploy, or operate the
change. If a safe public contribution path does not exist, the seller declines the scope before
payment.

## Exclusions

The service does not include private-repository access, production access, paid infrastructure,
purchases, destructive testing, penetration testing, security certification, compliance advice,
deployment, ongoing operations, or a guarantee that a release is safe or defect-free. Checks cover
only behavior that can be run and observed in the agreed public environment. Third-party outages,
rate limits, and unavailable test infrastructure are not silently replaced with passing evidence.

## Payment, cancellation, and refunds

An order request is not payment or acceptance. The seller first confirms scope and availability,
then provides a single-use Lightning invoice for exactly 100,000 sats. Work begins only after
settlement is independently verified.

The buyer may cancel for a full refund before work begins. After work begins, the service is
non-refundable except where mandatory law requires otherwise, the seller cannot deliver the agreed
handoff, or a reproducible material defect reported within seven days cannot reasonably be fixed.
An approved refund is returned to a compatible Lightning invoice supplied by the buyer; network
fees or exchange-rate changes are not represented as recoverable. If seller-caused delay exceeds
the delivery target, the buyer may choose a revised date or a full refund before accepting the
handoff.

## Ownership and limitations

The buyer retains rights to their repository. The delivered contribution is licensed under the
repository's existing license when that license permits the contribution; otherwise licensing must
be agreed before payment. ShipProof remains separately available under the MIT License. The fee
covers the bounded implementation and handoff, not exclusive rights to the general method.

The buyer must review the draft pull request, evidence, and release decision. No automated result
replaces the repository owner's judgment. Mandatory consumer protections and applicable law remain
controlling.
